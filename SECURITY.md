# Security policy

## Supported versions

Only the latest code on the `main` branch is actively supported for security fixes. LumiStripe is currently distributed as an early-stage project without a separate release-support matrix.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/woobble/LumiStripe/security/advisories/new). If private reporting is unavailable, email `felix@sternberg.cx` with the subject `LumiStripe security report`.

Do not open a public issue or include secrets, pairing codes, private hostnames, or other sensitive data in a public discussion. Include the affected commit or version, reproduction steps, impact, and any suggested mitigation that can be shared safely.

We will acknowledge reports when practical, investigate them, and coordinate disclosure with the reporter. Response and remediation times are not guaranteed for this personal project.
